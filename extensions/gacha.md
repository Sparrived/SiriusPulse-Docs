# 群友图鉴插件

她给群里的每个人画一张收藏卡，大家每天抽一张、慢慢集齐，还能互相送、互相换。卡面上的称号、技能和批注是她自己写的，属性来自真实的聊天数据；群里热闹的名场面会被她做成限量卡，三星卡还能觉醒成她专门画了插画的超级卡。回复用的是她自己的口气：常说的话来自她每周自己写的台词本。所以被画的人会想截图，没被画到的人会想多聊两句。

![群友收藏卡预览（三星，带两句悄悄话），全部为演示数据](/gacha-card-preview.png)

外部插件位于 `plugins/gacha/`（`plugins/` Git submodule），需要 Sirius Pulse **1.3.0+**。插件默认启用（不想要可以在 WebUI 的插件管理里关掉「**群友图鉴**」），所有群成员都能玩，私聊里不能玩。

## 指令

| 指令 | 行为 |
| --- | --- |
| `/抽卡` | 抽一张本群的卡，附上她的一句台词；每次刷新后每人 `draws_per_day` 次（默认 1），见[抽卡次数的刷新](#抽卡次数的刷新) |
| `/抽卡 刷新时间` | 看本群每天几点刷新、下次是什么时候 |
| `/抽卡 刷新时间 08:00 20:00` | **仅 root**：给本群另设刷新时刻（可以写好几个）；`/抽卡 刷新时间 默认` 恢复插件配置 |
| `/抽卡 刷新` | **仅 root**：马上刷新本群，大家的次数都回来了；同一天可以刷新多次 |
| `/图鉴` | 一张图展示你在本群的收集进度，没抽到的卡是问号（限量卡会标出还剩几份） |
| `/卡 <名字或编号>` | 看一张你已经抽到的卡（`/卡 阿明`、`/卡 17`）；没抽到的不能偷看 |
| `/送卡 <人> <编号>` | 把一份卡送给群友，`<人>` 可以写名字，也可以直接 @ |
| `/交换 <人> <我的编号> <他的编号>` | 提出换卡（`/交换 @小红 17 换 32`），对方 10 分钟内发 `/同意交换` 或 `/拒绝交换` |
| `/升星 <编号>` | 用一份重复的卡把这张升一星（最多 3 星），她会在你那张上多写一句只给你的「悄悄话」 |
| `/觉醒 <编号>` | 三星卡觉醒成 SSR 超级卡：她专门为你画一张插画，画好在群里叫你；只属于你，不能送也不能换 |
| `/我的卡` | 看她给你画的那张 |
| `/我的卡 退出` | 不想被画进图鉴：画了你的卡（包括你出演的名场面）连同大家手里的那几张一起删掉，以后也不再画你 |
| `/我的卡 加入` | 回到图鉴，之后她会重新给你画一张 |
| `/我的卡 画我` | 同意她画你的觉醒卡插画时**照你本人登记的形象**把你画进去（见下面的[画我](#画我)） |
| `/我的卡 不画我` | 撤回：以后只用象征物代表你，已经照你画好的插画立刻从卡上撤下 |

## 四种卡

| 稀有度 | 卡 | 怎么来 |
| --- | --- | --- |
| **R** | 常驻卡 | 每个够格的群友一张 |
| **SR** | 心情卡 | 她心情好的时候，给已经有卡的人随手再画一张，换一个角度写；每个群每天最多一张，同一个人 30 天内最多一张 |
| **SSR** | 觉醒卡 | 三星卡 `/觉醒` 后，她换一个称号和技能、写一句给收藏者的话，再专门画一张插画；只此一份，抽卡抽不到 |
| **UR** | 名场面卡 | 群里一段很多人一起接梗、情绪很高的十分钟，她觉得值得，就做成引用一句原话的卡，并配一张插画；**限量** `moment_supply` 份（默认 3），每个群一周最多一张 |

![名场面卡预览，全部为演示数据](/gacha-moment-preview.png)

### 名场面怎么认出来

后台每次心跳在近 24 小时的认知事件里找一段十分钟：至少 12 条消息、至少 3 个人开口，按"消息数 ×（0.5 + 平均唤醒度）"挑最热闹的那段。然后把那段时间里**本群**的原话（跳过指令、跳过退出图鉴的人）交给她判断：普通闲聊、吵架、刷屏不算，好笑的、翻车的、一起接梗的才算。算的话她选出最有代表性的一句的**编号**，卡上引用的是那句原话本身，不是她改写的；出演名单就是那段里开口的人。

每个群每天最多判断一次（找到候选才算一次，判断失败也不在每次心跳上重试）。

## 超级卡的插画

![觉醒卡预览，插画为占位图，全部为演示数据](/gacha-awakened-preview.png)

觉醒卡和名场面卡的插画是她**真的画的**：她先用自己的口气写出画面（场景、构图、光线），再通过框架的插件生图入口 `EngineProxy.generate_image()` 交给 AMKR 的 `image_generate` 任务去画，并带上她自己的形象图（`{persona}/assets/`，见 [Plugins API → 生图](../reference/plugins-api#生图)），画里出现的她和平时一个样。

- **默认画里没有真实的人**：群友只用象征物表示（一只动物、一个剪影、一件道具），提示词和生图描述都明确禁止画真实人物的脸、文字和号码。唯一的例外是本人同意的[画我](#画我)。
- **在后台慢慢画**：`/觉醒` 只排队，马上回一句；画图任务每 30 秒取一张，画好后她在群里说一句并附上新卡面。每张最多试两次，都失败就作罢并告诉本人（什么都没扣，可以再 `/觉醒`）。
- **有每日额度**：`art_per_day`（默认 3，觉醒与名场面合计），用完的排到第二天；设为 0 就不画插画，也不能觉醒。插件生图不计入部署方的人物生图额度。
- 插画卡比普通卡高 120 像素，多出的部分全部给主图。

## 画我

群友可以让她把自己真的画进觉醒卡插画里，但这件事只能由**他本人**决定，而且必须经过框架的视觉资产系统，插件自己碰不到任何人的照片。

**什么时候照本人画**：卡上的人（不是收藏者）自己发过 `/我的卡 画我`，**并且**在视觉资产系统里登记了已启用的正式形象（见[人物档案与视觉资产](../guide/person-profiles)，比如对她说“记一下我的样子”并附照片）。两条都满足，他那张卡觉醒时，插画里就有他本人；缺一条就和以前一样用象征物。只有觉醒卡这样画；名场面卡一张里有好几个人，始终只用象征物。

**同意怎么记**：`/我的卡 画我` 这条消息本身就是证据。插件通过 `EngineProxy.grant_person_image_consent()` 在视觉资产系统里记一条授权：人物和被授权人都是他自己，只允许把他的形象图用于生图，只在这个群有效，标着来自群友图鉴，留审计。别人替他说、或者宿主没能为这条消息记下来源（比如人物模块故障），都不会记成同意。`gacha.db` 里只存这条授权的编号作备忘。

**画的时候**：插件调 `EngineProxy.generate_person_image()`，由框架编译他的正式形象与参考图序、扣**部署方人物生图额度**、预检、领取提交许可、生成，再核验一次授权才交付（见 [Plugins API → 受管人物生图](../reference/plugins-api#受管人物生图)）。她写画面时被要求不描写他的长相，长相全交给他登记的形象图；她自己若也登记了正式形象，会作为第二个人物一起画。

**没画成时**：照旧用象征物画完这张，不会让觉醒卡空等。原因如果不是他本人的选择，她会在发卡的那句话后面如实补一句，比如“（这次没能照 阿明 本人的样子画：人物生图的额度用完了，先用象征物代替。）”；同意了但还没登记形象图时，`/我的卡 画我` 当场就会告诉他。

**撤回（`/我的卡 不画我`）**：

- 以后不再照他画：插件这边的同意立刻删掉，视觉资产系统里的授权撤回；
- **已经照他画好的插画立刻撤下**：插画文件和当时发到群里的卡面图都删掉，卡本身（称号、技能、批注、收藏者手里的那份）保留，回到没有插画的样子；视觉资产系统里依据这条同意画出的结果也一并隔离；
- 正在画的那张：框架在提交前发现撤回就取消、退额度；已经交给上游的，结果隔离不交付，插件改用象征物画完这张。插件保存插画前也会再查一次同意。

`/我的卡 退出` 同样会撤回同意，并删掉画了他的所有卡和它们的插画文件；回来（`/我的卡 加入`）也不会恢复同意，需要重新说 `/我的卡 画我`。

## 她的声音

图鉴里的每个字都走宿主的对话生成链路（`EngineProxy.generate_text`，与聊天相同，带完整人设），提示词只提内容要求，口气交给她自己的人设。

- **台词本**：抽到新卡、抽到重复、抽到自己、今天抽过了、送卡、交换、退出与加入……这些天天要说的话，她每周写一本自己的台词本（一次模型调用），每个场合写几句、留好占位符，插件按场合挑一句填上名字。占位符不对、太长的句子丢掉；某个场合一句可用的都没有，就退回保底句。写失败了当天不再重试。
- **现场说**：抽到 SR 以上的新卡、升星的悄悄话、觉醒卡画好时，她现场说一句。
- 指令用法、交换怎么同意这类规则说明由系统补上，不交给台词本。

## 一张卡怎么来

- **谁会被画**：在这个群里说过至少 `min_messages` 句话（默认 20）、没有退出的人。她自己不在卡池里。
- **在哪些群画**：只在有人 `/抽卡` 过的群里画。插件默认启用，没人玩的群不会被画、也不花模型调用。
- **什么时候画**：后台每约 10 分钟一次心跳，先给还没有卡的人画常驻卡，再看心情画心情卡，最后找名场面；每次心跳最多 `cards_per_beat` 张（默认 2），整个人格每天最多 `cards_per_day` 张（默认 20，常驻卡、心情卡、名场面合计；觉醒卡用的是插画额度）。每张一次模型调用（任务名 `plugin_generate`，带人设）；写坏的卡面整张丢弃，下次再画。一个群第一次 `/抽卡` 时卡池还是空的，会当场先画一张。
- **抽卡的花费**：抽到 R 时台词是模板，不调用模型；抽到 SR 以上时她会亲口说一句（一次模型调用，没写成就只用模板台词）。卡面是本地 Pillow 画的 PNG，头像用群友公开的 QQ 头像（缓存一周，拿不到就画名字的第一个字）。
- **升星**：一次模型调用写那句悄悄话；没写成就不扣卡。
- **觉醒**：一次模型调用写觉醒卡面和画面、一次生图、一次现场说话。

### 属性

| 属性 | 来源 |
| --- | --- |
| 话痨 | 本群发言数在本群够格群友里的百分位 |
| 夜行 | 近 30 天凌晨 0–5 点说话的占比，30% 即拉满 |
| 情绪 | 近 30 天情绪效价的起伏（标准差） |
| 默契 | 和她的互动程度（`engagement_rate`） |
| 资历 | 从第一次在本群说话到现在，满一年拉满 |

夜行和情绪需要至少 10 条认知事件，不够时卡面画成 `??`。名场面卡没有属性。

## 稀有度、心情与保底

出率 R 75%、SR 20%、SSR 4.5%、UR 0.5%，第 40 抽保底 SSR 以上。某个稀有度在卡池里还没有卡（或者限量卡已经发完）时，结果落到最近一档抽得到的稀有度，保底继续累计；卡池里真的有抽得到的 SSR 以上时，抽卡回复才会提示距离保底还有几抽。

**她心情好的时候**（情绪效价 ≥ 0.45，基线是 0.2）大家手气也好一点：SR、SSR、UR 的出率都乘以 1.2，多出来的从 R 里扣，抽卡回复会带上一句"今天我心情好，手气给你们调高了一点"。

限量卡在发卡的同一个事务里占名额：两个人同时抽到最后一份时，晚到的那位会换一张重抽，不扣次数。

## 抽卡次数的刷新

抽卡次数按「轮」算：每到一个刷新时刻就开始新的一轮，每人每轮能抽 `draws_per_day` 次。

- **刷新时刻**：插件设置 `refresh_times`（中国时间，默认 `00:00`），一天可以写好几个，用逗号、顿号或空格隔开，比如 `00:00, 12:00, 20:00`；写错的时刻跳过，一个都不对就按 `00:00`。root 可以在群里用 `/抽卡 刷新时间 …` 给单个群另设，`/抽卡 刷新时间 默认` 恢复。
- **手动刷新**：root 在群里发 `/抽卡 刷新`，本群从这一刻起是新的一轮；同一天可以刷新好几次。只刷新次数，保底不动。
- **谁是 root**：NapCat 适配器配置（`adapters.json`）里的 `root`，也就是主人的 QQ 号。插件只比对平台给的发送者账号，不看昵称；没配 `root` 时谁都不能手动刷新或改刷新时间。
- **不会白送一轮**：插件记的是每个人上次真正抽卡的时刻，只有在那之后真的过了一个刷新时刻（或者手动刷新了一次），次数才回来。所以 root 改刷新时间——比如下午两点把 `00:00` 改成 `08:00、20:00`——上午已经抽过的人要等到 20:00。
- 次数用完时，她说完话后系统会补上下次几点刷新（手动刷新预测不了，不算在内）。
- 从按自然日刷新的旧版本升级时，当天已经抽过的人这一轮仍算抽过。

## 送卡与交换

- 送卡和交换都只在本群里进行，`<人>` 只在本群认识的人里找：名字、群昵称，或者 @ 出来的 `qq_号`；有歧义时会请你换个说法。
- 交换要对方 10 分钟内 `/同意交换` 才成交。成交时双方各交出一份、各收到一份，在同一个事务里完成；如果某一方在这期间把那张卡送走了，整笔作废，谁也不少一张。同一对人之间只保留最新的一份交换。

## 隐私边界

- **卡池按群隔离**：同一个人在两个群里是两张不同的卡。写卡面的材料只有这个人在**本群**的公开发言（跳过 `/` `#` `!` 开头的指令），私聊和别的群的话不会进去；名场面也只取本群那十分钟里的原话。
- 写卡的提示词禁止拿外貌、身材、性别、地域、疾病、家庭、收入开玩笑，也不许编造没发生的事。
- 本人随时 `/我的卡 退出`：画了他的常驻卡、心情卡，以及他出演的名场面卡，都会从所有人的收藏里删掉（插画文件一起删掉）；他之后说的话也不再进名场面的材料。
- 插画里出现真实的人，只能是本人 `/我的卡 画我` 同意、并在视觉资产系统里登记了形象的那位；授权、额度、审计都在框架里，本人随时 `/我的卡 不画我` 撤回。

## 数据

```
{persona}/artifacts/gacha/
├── gacha.db        # 卡池、收藏（份数、星级、悄悄话）、抽卡次数与保底、各群刷新设置与手动刷新、交换、画图任务、退出名单、「画我」的同意（SQLite）
├── art/            # 觉醒卡与名场面的插画
├── announce/       # 插画画好时发到群里的卡面
└── avatars/        # 群友 QQ 头像缓存，一周过期
```

每日画卡额度（`mint_ledger`）、每日插画额度（`art_ledger`）、每个群当天是否判断过名场面（`moment_checks`）、她的台词本（`script`）与当天是否已经试写过（`script_tried`）记在插件数据文件 `_plugin_gacha_data.json` 里。第一期留下的 `gacha.db` 打开时会自动补上新列，已有的卡都按常驻卡处理。「画我」的授权本身、照本人画的任务与结果记在框架的视觉资产系统里，`gacha.db` 只记授权编号，以及哪张卡的插画是照本人画的（`art_likeness`，撤回时据此撤下）。
