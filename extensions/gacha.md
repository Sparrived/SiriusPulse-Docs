# 群友图鉴插件

她给群里的每个人画一张收藏卡，大家每天抽一张、慢慢集齐。卡面上的称号、技能和批注是她自己写的，属性来自真实的聊天数据，所以被画的人会想截图，没被画到的人会想多聊两句。

![群友收藏卡预览，全部为演示数据](/gacha-card-preview.png)

外部插件位于 `plugins/gacha/`（`plugins/` Git submodule），需要 Sirius Pulse **1.3.0+**。插件默认启用（不想要可以在 WebUI 的插件管理里关掉「**群友图鉴**」），所有群成员都能玩，私聊里不能玩。

## 指令

| 指令 | 行为 |
| --- | --- |
| `/抽卡` | 抽一张本群群友的卡，附上她的一句台词；每人每天 `draws_per_day` 次（默认 1），按中国时间的自然日重置 |
| `/图鉴` | 一张图展示你在本群的收集进度，没抽到的卡是问号 |
| `/卡 <名字或编号>` | 看一张你已经抽到的卡（`/卡 阿明`、`/卡 17`）；没抽到的不能偷看 |
| `/我的卡` | 看她给你画的那张 |
| `/我的卡 退出` | 不想被画进图鉴：你的卡连同大家手里的那几张一起删掉，以后也不再画你 |
| `/我的卡 加入` | 回到图鉴，之后她会重新给你画一张 |

![图鉴预览，全部为演示数据](/gacha-collection-preview.png)

## 一张卡怎么来

- **谁会被画**：在这个群里说过至少 `min_messages` 句话（默认 20）、没有退出的人。她自己不在卡池里。
- **在哪些群画**：只在有人 `/抽卡` 过的群里画。插件默认启用，没人玩的群不会被画、也不花模型调用。
- **什么时候画**：后台每约 10 分钟画一次，每次最多 `cards_per_beat` 张（默认 2），整个人格每天最多 `cards_per_day` 张（默认 20），最活跃的人先画。每张卡一次模型调用（任务名 `plugin_generate`，带人设）；写坏的卡面整张丢弃，那个人等下一次再画。一个群第一次 `/抽卡` 时卡池还是空的，会当场先画一张。
- **抽卡不花模型调用**：台词是模板，卡面是本地 Pillow 画的 600×900 PNG，头像用群友公开的 QQ 头像（缓存一周，拿不到就画名字的第一个字）。

### 属性

| 属性 | 来源 |
| --- | --- |
| 话痨 | 本群发言数在本群够格群友里的百分位 |
| 夜行 | 近 30 天凌晨 0–5 点说话的占比，30% 即拉满 |
| 情绪 | 近 30 天情绪效价的起伏（标准差） |
| 默契 | 和她的互动程度（`engagement_rate`） |
| 资历 | 从第一次在本群说话到现在，满一年拉满 |

夜行和情绪需要至少 10 条认知事件，不够时卡面画成 `??`。

## 隐私边界

- **卡池按群隔离**：同一个人在两个群里是两张不同的卡。写卡面的材料只有这个人在**本群**的公开发言（跳过 `/` `#` `!` 开头的指令），私聊和别的群的话不会进去。
- 写卡的提示词禁止拿外貌、身材、性别、地域、疾病、家庭、收入开玩笑，也不许编造没发生的事。
- 本人随时 `/我的卡 退出`，卡会从所有人的收藏里删掉。

## 稀有度与保底

出率表是完整的（R 75%、SR 20%、SSR 4.5%、UR 0.5%，第 40 抽保底 SSR 以上），但第一期卡池里只有 **R 常驻卡**：某个稀有度还没有卡时，结果会落到最近一档有卡的稀有度，保底继续累计。SR 心情卡、SSR 事件卡和 UR 名场面卡会在后续版本里由她自己发行；卡池里真的有 SSR 以上时，抽卡回复才会提示距离保底还有几抽。

## 数据

```
{persona}/artifacts/gacha/
├── gacha.db        # 卡池、收藏、每日抽卡记录与保底、退出名单（SQLite）
└── avatars/        # 群友 QQ 头像缓存，一周过期
```

每日画卡额度记在插件数据文件 `_plugin_gacha_data.json` 的 `mint_ledger` 里。
