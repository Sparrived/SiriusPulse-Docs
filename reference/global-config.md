# 全局配置

在 **WebUI → 全局设置** 页面配置系统级参数。无需直接编辑文件。

---

## 系统参数

| 字段 | 默认值 | 说明 |
|------|--------|------|
| WebUI 端口 | `8080` | 管理面板 HTTP 端口 |
| WebUI 地址 | `127.0.0.1` | 监听地址 |
| NapCat 起始端口 | `3001` | 多人格时每人格递增 1 |
| Embedding 模型 | `BAAI/bge-small-zh-v1.5` | Hugging Face 模型名 |
| Embedding 端口 | `5555` | 微服务端口 |
| Embedding 设备 | `cpu` | cpu / cuda |
| 插件目录 | `plugins` | 相对项目根 |
| 技能目录 | `skills` | 相对项目根 |
| 日志级别 | `INFO` | DEBUG / INFO / WARNING / ERROR |
| 日志格式 | `console` | console / file |

---

## 编排策略

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 计划模式启用 | `false` | 启用隐藏计划会话。 |
| 计划模式限制普通工具 | `false` | 启用计划模式时，限制普通聊天只使用轻量运行时工具。 |
| 计划模式允许轻量聊天 | `true` | 计划活动期间允许在同一群组中进行无关的轻量聊天。 |
| 计划模式状态通知启用 | `false` | 隐藏计划开始时发送简短的角色状态消息。 |
| 计划模式状态通知最小间隔 | `45.0` | 计划状态消息之间的最小间隔秒数。 |
| 计划模式进入消息 | `我看到了，这个得稍微捋一下。` | 进入隐藏计划模式时发送的可见状态文本。 |
| 计划模式更新消息 | `补充我看到了，我会按新的前提来。` | 接受计划事件时发送的可见状态文本。 |

---

## 自动创建

首次运行 `sirius-pulse webui` 时系统会自动生成默认配置文件，无需手动创建。
