# Skills API

Python 模型：`SkillDefinition`、`SkillParameter`、`SkillResult`、`SkillContentBlock`、`SkillInvocationContext`、`BackgroundTaskSpec`、`TriggerSpec`。

WebUI API：`GET /api/persona/skills`、`POST /api/persona/skills/{skill_name}/toggle`、`GET /api/persona/skills/{skill_name}/config`、`POST /api/persona/skills/{skill_name}/config`、`GET /api/persona/skill-history`。
