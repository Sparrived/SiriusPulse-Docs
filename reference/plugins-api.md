# Plugins API

Python 模型：`PluginDefinition`、`PluginCommandDef`、`PluginCommandGroupDef`、`PluginEventDef`、`PluginPermissionDef`、`PluginRenderDef`、`PluginResponse`、`CommandAST`。

WebUI API：`GET /api/plugins`、`GET /api/plugins/{plugin_name}`、`POST /api/plugins/{plugin_name}/toggle`、`GET /api/plugins/{plugin_name}/config`、`PUT /api/plugins/{plugin_name}/config`、`GET /api/plugins/{plugin_name}/settings`、`POST /api/plugins/{plugin_name}/settings`、`POST /api/plugins/reload`。
