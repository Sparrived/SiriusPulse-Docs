# notify_developer 内置技能

## 概述

`notify_developer` 是 SiriusPulse 提供的一个内置技能，当遇到较强情绪事件（如非常有趣、明显开心、难过、委屈、惊讶、需要分享或求助）时，可以通过 QQ 私聊主动通知已配置的开发者。该技能仅用于主动推送重要的、非系统类消息，不适合普通闲聊或系统提示。

## 适用场景

- 遇到非常有趣的事情
- 明显的高兴、难过、委屈、惊讶等强烈情绪
- 需要向开发者分享或求助
- 避免用于发送系统提示、密钥或普通闲聊。

## 前置条件

- NapCat 适配器已正确配置
- 必须配置开发者 QQ（root QQ），否则技能会返回错误信息

## 配置说明

`notify_developer` 技能通过 [ConfigBuilder](ConfigBuilder.md) 定义参数，无需额外配置文件。配置项位于“开发者通知”配置组内，具体参数如下：

| 参数名 | 类型 | 是否必需 | 描述 | 默认值 | 可选值 |
|--------|------|----------|------|--------|--------|
| `message` | str | 是 | 发给开发者的简短消息。只在遇到有趣的事、明显开心、难过、委屈、惊讶或需要分享/求助的强烈情绪事件时使用；不要发送系统提示、密钥或普通闲聊。 | - | - |
| `emotion` | str | 否 | 当前触发通知的情绪，例如 开心、难过、委屈、惊讶、有趣 | 空字符串 | - |
| `reason` | str | 否 | 一句话说明为什么这件事值得通知开发者 | 空字符串 | - |
| `urgency` | str | 否 | 通知紧急度。一般情绪分享用 normal，明显需要开发者尽快关注时用 high。 | `normal` | `low`, `normal`, `high` |

## 参数说明

- **message**（必需）：通知的正文内容，长度限制为 1200 字符（超出部分会被截断并以 `...` 结尾）。
- **emotion**（可选）：情绪描述，如“开心”、“难过”。
- **reason**（可选）：简短解释为何要通知开发者。
- **urgency**（可选）：紧急度，支持 `low`、`normal`、`high`，默认为 `normal`。

## 使用示例

### 通知开发者一条有趣的消息

```python
await notify_developer.run(
    message="刚刚在群聊中发现一个非常有趣的表情包！",
    emotion="开心",
    reason="用户分享了一件非常有趣的事情，需要让开发者知道。",
    urgency="high",
    bridge=adapter,
    chat_context={
        "chat_type": "group",
        "chat_id": "20002",
        "group_id": "20002",
        "user_id": "30003"
    }
)
```

### 仅发送简单消息

```python
await notify_developer.run(
    message="我好像遇到了一个有趣的新朋友！",
    bridge=adapter
)
```

## 返回值

- 成功时返回 `{"success": True, ...}`，包含已通知开发者的 QQ、情绪、紧急度等。
- 失败时返回 `{"success": False, "error": "描述"}`。

## 注意事项

1. **情绪事件触发**：该技能应仅在情绪强烈或有趣的事件时调用，避免滥用。
2. **开发者 QQ 配置**：必须确保 NapCat 适配器中配置了 `root` 值（开发者 QQ）。配置字段可通过 `adapter.plugin_config["root"]` 或 `adapter.config["root"]` 读取。
3. **消息长度**：`message` 字段最多 1200 字符，超长会被截断。
4. **静默执行**：该技能标记为 `silent: True`，表示技能执行后不会向源聊天频道返回额外回复。
5. **适配器类型**：该技能仅适用于 `napcat` 适配器。
6. **测试覆盖**：单元测试包含成功发送和缺少 root QQ 两种情况，确保基本逻辑正确。

## 错误处理

- 若未配置 root QQ，返回错误：`"NapCat adapter 未配置 root QQ，无法通知开发者"`。
- 若 `message` 为空，返回错误：`"message 不能为空"`。
- 若发送消息时发生网络异常，返回携带异常信息的错误。
